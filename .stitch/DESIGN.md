# Design System - Vetis Digital

## 6. Design System Notes for Stitch Generation
(Incluir SIEMPRE este bloque en los prompts de Stitch para consistencia visual)

**CRITICAL RULE: THIS IS A WEBSITE, NOT AN APP.**
- DO NOT INCLUDE sticky bottom navigation bars, app-like tabs, or mobile OS status bars. This is a responsive WEBSITE layout for mobile.

**AESTHETICS & BRANDING:**
- **Estilo:** Diseño nivel $10,000 USD. Premium, altamente dinámico, didáctico y moderno. Sensación de alta gama pero amigable y que transmite mucha confianza.
- **Colores:** Fondos off-white o crema muy sutil. Acentos dinámicos y degradados muy sutiles en colores sofisticados (verdes profundos inspirados en la naturaleza, terracota para botones/CTAs, dorados sutiles). Replicar EXACTAMENTE EL MISMO COLOR DE FONDO en el footer de todas las páginas (tomando el del Inicio).
- **Tipografía:** Usar Google Fonts elegantes, sans-serif modernas como 'Outfit' o 'Inter' para UI y cuerpo, posiblemente combinada con tipografías serif elegantes para encabezados principales.
- **Imágenes (CRÍTICO):** Las imágenes DEBEN estar 100% relacionadas con el texto. Jamás usar vectores, ilustraciones o imágenes que parezcan de IA. SOLO usar fotografías HD, fotorealistas, transmitiendo confianza y calidez (tutores reales conviviendo con PERROS y GATOS, ambos son obligatorios).
- **UI:** Glassmorphism muy sutil, sombras difusas extensas, border-radius redondeados sutiles y elegantes.

**INTERACTIONS & LAYOUT:**
- Fuerte jerarquía visual. Elementos agrupados no deben chocar visualmente. Mantener amplísimo whitespace (espaciado generoso).
- Separación clarísima entre texto y fondos de imagen para que sea 100% legible y limpio.

**GLOBAL COMPONENTS (APPLY TO EVERY PAGE):**
1. **FAQ Block:** This block (with 6 FAQ dropdowns/accordions) MUST ONLY appear on the "Inicio" (Home) and "Nosotros" (About Us) pages, placed exactly above the footer. DO NOT include FAQs on the other 5 pages.
2. **GLOBAL FOOTER:** (Debe tener el mismo color base que el header/fondo predominante del Inicio):
   - **Columna 1:** Logo Vetis Digital. Frase: "Entiende mejor. Cuida mejor. Vive mejor junto a tu mascota."
   - **Columna 2:** Enlaces: Inicio, Biblioteca, Audioteca, Nosotros, Blog, Afiliados, Contacto.
   - **Columna 3:** Términos y Condiciones, Política de Privacidad, Política de Reembolsos, Política de Cookies, Aviso Legal.
   - **Bottom:** © 2026 Vetis Digital. Todos los derechos reservados. (NO INCLUIR NADA DEBAJO DE ESTO).
